## О моде
Мод для дополнительной защиты игровых аккаунтов на серверах посредством запроса пароля при входе на сервер.

## Команды
```/register <password>``` - регистрация пользователя.

```/login <password>``` - авторизация пользователя

```/change_password <new_password>``` - смена пароля
